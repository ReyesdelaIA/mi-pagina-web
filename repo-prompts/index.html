Extracto de chat largo para nuevo chat
Claude
prompt.txt
Haz un resumen denso de este chat para que yo lo pueda pegar en un nuevo chat y continuar sin perder contexto. Incluye: - El objetivo principal de la conversación - Decisiones tomadas - Código, configuraciones o archivos relevantes (con detalles exactos) - Pendientes o próximos pasos - Cualquier dato clave (rutas, nombres, URLs, credenciales técnicas, etc.) Formato de entrega: un único bloque bash (```bash ... ```) con todo el resumen adentro, listo para copiar y pegar directamente en un nuevo chat sin modificar nada.
Úsalo al final de cualquier chat largo
Crear instrucciones de proyecto en Markdown
Claude
prompt.txt
Vas a ayudarme a crear el archivo de instrucciones (en formato Markdown) para un nuevo proyecto de Claude. Este archivo será el contexto permanente que Claude leerá en TODOS los chats de este proyecto, así que debe ser claro y completo. El proyecto se llama "[nombre del proyecto]". Te lo explico: [describe tu proyecto]. Antes de escribir nada, hazme entre 3 y 5 preguntas clave para entender bien qué necesito. Cuando responda, redacta el MD con estas secciones: - Rol (quién debe ser Claude en este proyecto) - Objetivo (para qué existe el proyecto) - Contexto relevante - Tono y estilo de las respuestas - Restricciones y qué evitar - Formato de salida esperado Al final, sugiéreme 2 mejoras que yo no haya considerado.
